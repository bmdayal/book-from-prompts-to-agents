Staged change 3

Cache user profiles for 5 minutes

The upstream profile API allows 60 requests per minute, so fetching a profile on every getProfile call risks hitting the rate limit. Add a small in-memory cache with a 5-minute TTL and use it in getProfile, so repeat lookups within that window skip the upstream call.

Add a test that checks a stored value is returned from the cache.
