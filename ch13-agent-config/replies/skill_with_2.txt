Staged change 1

Keep max characters before truncation ellipsis

truncate() dropped one character too many before appending the
ellipsis. Keep the first max characters, then append it. The result
can now be max + 1 characters long, so callers that need a hard limit
should pass a smaller max.

Staged change 3

Cache user profiles for five minutes

The upstream profile API allows 60 requests per minute. Fetching a
profile on every call risks hitting that limit, so keep each profile
in an in-memory cache for 5 minutes. getProfile() now checks the cache
first and stores fresh results. Add a test for the cache round trip.
