# Starter prompt library

Fifteen ready-made entries from the book (Chapter 3), in the format Chapter 10 describes.

- Open `INDEX.md` to browse. Each entry is one short file.
- Copy `TEMPLATE.md` to add your own.
- Entries marked `tested_on: "not yet"` have not been run by you. Run each once, then fill in the date and an example.
- Never put passwords, client names or private data into an entry. Use [BRACKETS] and fill them in when you run the prompt.
- The `evals/` folder shows how to test an entry (Chapter 10, step 5).

- The `skills/` folder shows one entry promoted to a skill (checked for format, not run in a skill-aware tool).
