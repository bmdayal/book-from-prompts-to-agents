# Document a Function

## Use it when

your code has no comments and your teammates are guessing.

## The prompt

```text
Write documentation for the function below in
[YOUR TEAM'S STYLE, for example a Google-style docstring].
Include a one-sentence description, each parameter with
its type, the return value, the errors it can raise, and
one short usage example. Describe only what the code does,
not what it should do.

[PASTE FUNCTION]
```

Fill every [BRACKET] before you run it.

## Why it works

"only what the code does" matters. Left alone, AI tends to document the intention, which can differ from the behavior.
