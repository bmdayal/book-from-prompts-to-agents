# Translate Code to Another Language

## Use it when

you're moving code between languages or learning a new one.

## The prompt

```text
Convert this [LANGUAGE A] function to [LANGUAGE B]. Keep
the behavior identical, use current, idiomatic
[LANGUAGE B], and add a comment wherever the two languages
behave differently.

[PASTE FUNCTION]
```

Fill every [BRACKET] before you run it.

## Why it works

the comment rule is a built-in lesson. The differences it points out are exactly what trips people up.

## Make it yours

name the version of the target language if it matters to you.
