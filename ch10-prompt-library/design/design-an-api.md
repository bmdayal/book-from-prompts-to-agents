# Design an API

## Use it when

you're sketching the endpoints for a new app.

## The prompt

```text
Design a REST API for [WHAT THE APP DOES] using [FRAMEWORK]
and [AUTH METHOD, for example JWT].
List each endpoint as METHOD /path with a one-line purpose,
the request fields, the response fields, and the error
codes. Add advice on rate limiting.
Do not write implementation code. If anything is unclear,
ask me before you start.
```

Fill every [BRACKET] before you run it.

## Why it works

naming the framework and the login method removes two big guesses, and "ask me before you start" invites useful questions.
