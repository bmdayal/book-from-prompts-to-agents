# Shorten an email

## Steps

1. Ask who will read the email if the user has not said. The tone depends on it.
2. Rewrite the email so it is clearer and at least 25% shorter.
3. Keep every date, number, name, and request exactly as written.
4. Do not add anything the user did not say.
5. After the rewrite, add one line listing any softening phrase you removed (for example "I think" or "if you can"), so the user can decide whether to put it back.

## Never

- Invent a deadline, a number, or a promise.
- Make a request sound firmer or softer than the original without saying so.
