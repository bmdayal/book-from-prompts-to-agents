# Improve a Prompt You Already Use

## Use it when

a prompt works sometimes and fails other times.

## The prompt

```text
You are a prompt engineer. Here is a prompt I use:

[PASTE YOUR PROMPT]

Tell me what is ambiguous, what context is missing, and
what limits would help. Then give an improved version and
explain each change in one line. Keep my original goal.
```

Fill every [BRACKET] before you run it.

## Why it works

you're borrowing the AI's patience for a boring job. "Keep my original goal" stops it rewriting your idea into its own.

## Make it yours

add a sample of a bad result: "here's an answer I didn't like". It makes the diagnosis much sharper.

## Example

Paste a good input and the reply you got after your first run.
