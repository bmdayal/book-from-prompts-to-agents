# Chapter 9: the spending summary

- `march_statement.csv`: a made-up bank statement for one month.
- `summarize.py`: the developer-track script from the chapter. It sorts the transactions into categories and prints totals. Standard library only.

Run: `python3 summarize.py march_statement.csv`. The totals should be 1353.78 spent and 2400.00 income.

The main track of the chapter needs no code: paste the statement into an AI chat and follow the steps in the book. Use this script to check the AI's arithmetic.

All names, merchants and amounts are invented.
